# Prep Checklist · Nebius x NVIDIA Global AI Hackathon

Checked against the official Devpost page and rules on 15 October 2026. This checklist applies only to the separate online contest; it is not a checklist of rules for the Berlin Build Week event.

## Before continuing Sunday work

- [ ] Secure the local Berlin submission first; its internal deadline is 17:30 Berlin time unless organizers clarify otherwise.
- [ ] Read the current [Global overview](https://nebiusglobalaihackathon.devpost.com/) and [official rules](https://nebiusglobalaihackathon.devpost.com/rules); join the Global contest separately on Devpost.
- [ ] Resolve with the local organizer whether the Sunday project, pre-event work, data, code, and assets may be reused and publicly released. Local pre-build/IP rules are not published in the pages checked for the Berlin event.
- [ ] Ask Nebius/Devpost in writing whether local-event credits, mentoring, or other support affect the Global rules' financial/preferential-support restriction. Do not infer disqualification or eligibility.
- [ ] Verify the current submission deadline. Devpost lists **October 30, 2026 at 10:00am PDT**.

## Eligibility and evidence

- [ ] Confirm every entrant meets the official eligibility rules and designate an authorized representative if submitting as a team.
- [ ] Select the one track that best fits the working project. Read its exact technology requirements; the Global-wide baseline is a runtime call to Nebius Token Factory or use of Nebius AI Cloud compute, plus at least one NVIDIA open-source model.
- [ ] Confirm the project is genuinely viable for the chosen track. Treat the rules' stage-one theme/technology check as a pass/fail gate.
- [ ] Map one concrete artifact or demo moment to each equally weighted Global judging criterion: Technological Implementation, Design, Potential Impact, and Quality of the Idea. These are Global criteria only; do not apply them to the local Berlin judging unless its organizers publish them.
- [ ] If the project existed before August 26, 2026, record the significant updates actually made during the Global submission period and explain them accurately.

## Submission package

- [ ] Provide the project description, chosen track, working demo/hosted app/test-build URL (except the stated Physical AI exception), and any testing instructions.
- [ ] Publish the source repository with an open-source license visible on the repository page and a README with complete setup/run instructions.
- [ ] Upload a public YouTube demo **under three minutes** showing the project working. For Physical AI, include the required operating-hardware footage or key modules in action when there is no physical hardware.
- [ ] Complete the required feedback on Nebius Token Factory, AI Cloud, and NVIDIA tools/models used; be specific about onboarding, what worked, and what needs improvement.
- [ ] Keep the project available free of charge for judging/testing through the end of the currently listed judging period, **December 15, 2026 at 12:00pm Pacific Time**. Assign an owner for the app, hosting credits, model access, and dependency health; do not assume hackathon credits last that long.
- [ ] If access requires a login, provide any test credentials only through the Devpost testing instructions, never in the public repository.

## Award route and final checks

- [ ] Select the best-fitting submission track; the rules limit a project to at most one Overall **or** Track Award, plus one eligible Bonus Award.
- [ ] Pursue **Best Use of Tavily** only if a functional Tavily runtime call improves the workflow and can be demonstrated; don't add search as decoration.
- [ ] Complete the feedback submission if seeking **Most Valuable Feedback**.
- [ ] At the October 18 event, ask an organizer whether attending this in-person Build Week Hackathon qualifies for the Global Berlin City Winner award, and record the answer and source. Devpost's [rules](https://nebiusglobalaihackathon.devpost.com/rules) name participating IRL Builders & Brews events, and its [FAQ](https://nebiusglobalaihackathon.devpost.com/details/faqs) confirms in-person attendance. The [official Nebius event page](https://nebius.com/events/nebius-nvidia-ai-builders-hackathon) and [Luma listing](https://luma.com/big-gtc-hack) make October 18 a plausible route, but no reviewed official source confirms or excludes eligibility. The separate September 29 Berlin Builders & Brews listing is context, not a stated prerequisite. Check with Devpost if the on-site answer is unclear.
- [ ] Confirm rights and permissions for every contributor, dataset, model, library, logo, screenshot, and media asset; remove secrets and personal/confidential data.
- [ ] Open the final submission links in a clean browser session, save the Devpost submission receipt, and recheck the rules before the deadline.
