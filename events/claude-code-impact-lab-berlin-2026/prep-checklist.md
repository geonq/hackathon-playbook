# Prep Checklist · Claude Code Impact Lab Berlin

Checked against public pages on 15 October 2026. Confirm all times and rules with the host or attendee email.

## Before Saturday

- [ ] Confirm attendance/selection. The Luma listing showed registration closed.
- [ ] Confirm arrival time, building access, and what to bring; the primary event page does not publish an agenda.
- [ ] Follow the official [Claude Code setup guide](https://code.claude.com/docs/en/setup); run `claude --version` and `claude doctor`.
- [ ] Ask how Claude API credits are issued, what models/limits apply, and whether a separate account is needed.
- [ ] Prepare the [project brief](../../templates/project-brief.md) and a short list of problem-owner questions; do not arrive committed to a product idea.
- [ ] Ask whether any starter code or other pre-work is allowed. The public page does not state a pre-build policy.
- [ ] Ask about the actual partner/problem, approved data, deliverables, demo/submission timing, team size, and required tools.
- [ ] Clarify code ownership, open-source or donation terms, publication consent, and what “shared with Anthropic” entails.

## At kickoff

- [ ] Identify the actual user, current workflow, and one painful step.
- [ ] Confirm privacy, security, human-review, and data-use boundaries.
- [ ] Agree on one narrow end-to-end outcome and one observable measure.
- [ ] Assign owners for problem/scope, build/integration, evidence/safety, and demo/submission.
- [ ] Confirm the real cutoff and reserve the final 60–90 minutes for verification and rehearsal if the schedule permits.

## Before demo and submission

- [ ] Run the promised workflow from a clean state on approved examples.
- [ ] Be ready to explain what was tested, what failed, and what still requires a person.
- [ ] Check every official required field, link, and access setting.
- [ ] Remove credentials and unapproved personal or partner data from code, screenshots, and demo material.
- [ ] Rehearse the story and capture submission confirmation.
