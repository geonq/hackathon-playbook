# Repository Guidance

This is a public, provider-neutral hackathon preparation kit. Before changing it, read [README.md](README.md), the [sprint playbook](docs/PLAYBOOK.md), and [tool setup](docs/SETUP.md). For event-specific work, read that event's brief and source ledger.

Keep reusable skills in `skills/`; `.claude/skills/` contains the tracked Claude Code mirror. `.agents/` is ignored generated Codex install state; use `bash scripts/install-codex-skills.sh` on a checkout where it is writable. Do not claim `skills/` auto-loads in Codex.

Date event research, link claims to their sources, and separate organizer-confirmed facts from secondary reports, recommendations, and unknowns. Verify current official event details before relying on them. Never present preparation advice as an official rule or judging criterion.

Keep public files free of credentials, personal agent configuration, private paths, and session handoffs. Put reusable guidance in the README or docs; do not copy personal machine bootstrap instructions into this repository.
