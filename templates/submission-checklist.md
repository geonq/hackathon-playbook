# Submission Checklist

Confirm the official rules and deadlines before using this list.

- [ ] Required form, fields, and links identified
- [ ] Exact deadline and timezone confirmed with the organizer
- [ ] Required repository, access setting, and demo URL checked
- [ ] README explains the user, problem, setup, and limitations
- [ ] No secrets, personal data, private partner material, or unauthorized logos
- [ ] Required sponsor technology and its role described accurately
- [ ] Demo rehearsed and backup prepared if allowed
- [ ] Claims backed by observed tests; failures and limits disclosed
- [ ] Submission sent before the team's safe cutoff
- [ ] Receipt or confirmation captured
