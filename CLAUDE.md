# Claude Code Project Guidance

This is a public, provider-neutral hackathon preparation kit. Start with [AGENTS.md](AGENTS.md), [README.md](README.md), the [sprint playbook](docs/PLAYBOOK.md), and [tool setup](docs/SETUP.md).

For a specific event, read its brief and source ledger under `events/`. Verify current organizer facts before relying on dated logistics. Keep confirmed facts, secondary reports, recommendations, and unknowns distinct; do not present advice as an official rule or judging criterion.

The tracked skill source is `skills/`. Claude Code's project skill copies are under `.claude/skills/`; keep them in sync with their source files. Keep credentials, personal agent setup, private paths, and session handoffs out of public files.
